Per Mnemo il punto di partenza è semplice: **la tua memoria è tua**. Il prodotto è pensato perché l’uso quotidiano non dipenda dal condividere più dati del necessario.

### Offline-first di default

Il dataset principale è memorizzato **localmente sul dispositivo**. Questo riduce l’esposizione accidentale e mantiene l’app usabile con connettività scarsa.

### Sync cloud opzionale

Se abiliti funzioni legate all’account, Mnemo può sincronizzare **dataset e media cifrati** con l’infrastruttura HelloMnemo. L’obiettivo è continuità tra dispositivi senza trattare l’archivio come testo in chiaro nel cloud.

I dettagli evolvono con le release; considera questa pagina una panoramica e usa la documentazione per indicazioni operative.

### Cosa puoi fare

- Preferisci l’uso offline se non vuoi il sync cloud.
- Usa l’export quando ti serve un backup portatile (vedi [Import e export](docs/getting-started/import-export/)).
- Proteggi il dispositivo a livello di sistema (codice, cifratura disco, wipe remoto).

### Segnalazioni

Se ritieni di aver trovato un problema di sicurezza, scrivi a [info@hellomnemo.com](mailto:info@hellomnemo.com) con dettagli sufficienti a riprodurlo. Evita di pubblicare exploit prima che possiamo rispondere.
