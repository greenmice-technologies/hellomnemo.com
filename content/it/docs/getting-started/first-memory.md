Questa guida descrive una prima sessione semplice che verifica le basi: **cattura, navigazione, ricerca**.

## Prima di iniziare

- Installa Mnemo dallo store ufficiale della tua piattaforma.
- Decidi se parti **solo locale** o accedi per il sync (opzionale).

## Passi

1. **Crea o apri il tuo spazio di lavoro**  
   Completa l’onboarding fino alla timeline o alla home principale.

2. **Crea una nuova voce**  
   Aggiungi una nota che riconoscerai domani (es. “Prima voce Mnemo — giorno di setup”).

3. **Aggiungi contesto**  
   Imposta la data se serve, allega una foto se vuoi, salva.

4. **Ritrovala**  
   Usa la ricerca o sfoglia per giorno per riaprire la voce.

## Criteri di successo

Puoi rispondere con sicurezza: “Se l’ho salvata oggi, la ritrovo senza indovinare?”
