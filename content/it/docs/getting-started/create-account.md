Mnemo funziona **offline-first**. Molte persone lo usano a lungo in locale prima di abilitare il cloud.

## Quando un account aiuta

Crea un account HelloMnemo se vuoi:

- **Sync cifrato** di dataset e media tra dispositivi
- **Continuità** quando cambi telefono o usi più dispositivi
- Accesso a **funzioni cloud** offerte nella tua build (disponibilità per release e piattaforma)

## Cosa aspettarti

- I flussi di accesso sono nell’app, con autenticazione tramite provider ove applicabile.
- L’archivio resta **tuo**; il cloud è opzionale e può essere ignorato per un flusso solo locale.
