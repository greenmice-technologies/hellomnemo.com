Le note di release sono distribuite con le schede **App Store / Play Store** e le superfici di aggiornamento in app.

Questa pagina è un punto stabile sul sito per:

- temi ad alto livello per release (privacy, sync, superfici di richiamo)
- collegamenti alla documentazione quando il comportamento cambia

## Stato attuale

Le note pubbliche versionate appariranno qui man mano che le release saranno diffuse.

Per una build specifica in supporto, includi **piattaforma** e **versione app** quando scrivi a [info@hellomnemo.com](mailto:info@hellomnemo.com).
