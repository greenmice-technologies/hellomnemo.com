Le funzioni cloud di Mnemo sono **opzionali**. L’uso locale resta un percorso di prima classe.

## A cosa serve il sync

- mantenere una copia cifrata coerente tra dispositivi
- recuperare più rapidamente quando sostituisci l’hardware
- abilitare funzioni cloud offerte nella tua build

## Cosa non è

- una piattaforma di condivisione pubblica
- un sostituto dei tuoi backup se ti servono garanzie di disaster recovery forti

## Aspettative operative

Rete, accesso provider e spazio sul dispositivo influenzano l’affidabilità del sync. Se qualcosa sembra bloccato, inizia da [Risoluzione problemi](../troubleshooting/).
