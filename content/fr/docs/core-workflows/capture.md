## Objectif

Rendre « enregistrer ce moment » si facile que vous le faites vraiment — sans renoncer à la structure ensuite.

## Habitudes recommandées

- **Commencez court** ; développez seulement quand vous avez de l’énergie.
- **Joignez les médias tôt** (photo, audio) pendant que le contexte est frais.
- **Fiez-vous à l’horodatage** ; corrigez les fuseaux seulement si le sens change.

## Types d’entrées et médias

Mnemo combine **texte** avec **photos, vidéo, audio et documents** sur une même surface. Si un type manque dans votre build, mettez l’app à jour ou vérifiez les limites de plateforme.

## Rappels

Utilisez les rappels quand la mémoire est **temporelle** (« rappeler mardi ») plutôt que purement archivistique (« carnet de voyage »).
