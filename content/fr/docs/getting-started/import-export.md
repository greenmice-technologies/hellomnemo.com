Mnemo prend en charge des flux d’**import et d’export** pour que votre mémoire reste portable.

## Pourquoi c’est important

- **Sauvegarde** : une copie indépendante d’un seul appareil.
- **Migration** : passer à un nouveau téléphone ou tablette avec moins de friction.
- **Tranquillité** : l’archive n’est pas « enfermée » dans une installation.

## Conseils pratiques

Les libellés d’interface évoluent, mais l’intention est stable :

1. Utilisez **exporter** pour produire un paquet avec le jeu de données et les médias référencés.
2. Conservez le paquet là où vous maîtrisez (disque chiffré, cloud personnel, etc.).
3. Utilisez **importer** sur une nouvelle installation pour restaurer ou fusionner avec prudence (doublons).

## Sécurité

- Traitez les exports comme des données sensibles — **chiffrez le stockage** et limitez le partage.
- Après des changements importants, créez un export à jour plutôt que de supposer qu’une ancienne sauvegarde reste valide.
