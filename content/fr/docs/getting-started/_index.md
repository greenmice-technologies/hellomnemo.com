Utilisez ces pages dans l’ordre la première fois que vous ouvrez Mnemo.

1. [Créer un compte (facultatif)](create-account/) — uniquement pour les fonctions cloud.
2. [Votre premier souvenir](first-memory/) — capturez et retrouvez une première entrée.
3. [Importer et exporter](import-export/) — déplacez les données comme archive portable.

Ensuite, poursuivez avec les [Flux principaux](../core-workflows/).
