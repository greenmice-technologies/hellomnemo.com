Mnemo fonctionne **offline-first**. Beaucoup de personnes l’utilisent longtemps en local avant d’activer le cloud.

## Quand un compte aide

Créez un compte HelloMnemo si vous voulez :

- **Synchronisation chiffrée** du jeu de données et des médias entre appareils
- **Continuité** en changeant de téléphone ou en utilisant plusieurs appareils
- Accès aux **fonctions cloud** proposées dans votre build (disponibilité selon plateforme et version)

## À quoi s’attendre

- Les flux de connexion sont dans l’app, avec authentification par fournisseur le cas échéant.
- L’archive reste **à vous** ; le cloud est optionnel et peut être ignoré pour un flux uniquement local.
