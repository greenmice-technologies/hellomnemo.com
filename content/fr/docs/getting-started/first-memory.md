Ce guide décrit une première session simple qui valide le minimum : **capture, navigation, recherche**.

## Avant de commencer

- Installez Mnemo depuis la boutique officielle de votre plateforme.
- Choisissez de démarrer **uniquement en local** ou de vous connecter pour la synchro (facultatif).

## Étapes

1. **Créez ou ouvrez votre espace de travail**  
   Terminez l’intégration jusqu’à la chronologie ou l’écran d’accueil principal.

2. **Créez une nouvelle entrée**  
   Ajoutez une note que vous reconnaîtrez demain (ex. « Première entrée Mnemo — jour d’installation »).

3. **Ajoutez du contexte**  
   Réglez la date si besoin, joignez une photo si vous voulez, enregistrez.

4. **Retrouvez-la**  
   Utilisez la recherche ou parcourez par jour pour rouvrir l’entrée.

## Critère de succès

Vous pouvez répondre sereinement : « Si je l’ai enregistrée aujourd’hui, puis-je la retrouver sans deviner ? »
