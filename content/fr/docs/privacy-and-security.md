## Local d’abord

Considérez l’appareil comme la copie faisant autorité jusqu’à activation explicite de la synchro.

## Fonctions avec compte

Avec un compte HelloMnemo, la synchro peut envoyer vers le cloud des données chiffrées du jeu de données et des médias. L’intention est d’éviter de traiter le contenu comme texte clair dans les opérations courantes.

## Check-list

- système d’exploitation à jour
- code d’accès fort
- chiffrement du disque si disponible
- exports dans un stockage protégé
