Pour Mnemo, le principe de départ est simple : **votre mémoire est à vous**. Le produit est conçu pour que l’usage quotidien ne dépende pas du partage de plus de données que nécessaire.

### Offline-first par défaut

Votre jeu de données principal est stocké **localement sur l’appareil**. Cela réduit l’exposition accidentelle et garde l’app utilisable avec une connectivité faible.

### Synchronisation cloud optionnelle

Si vous activez des fonctions liées au compte, Mnemo peut synchroniser **jeu de données et médias chiffrés** avec l’infrastructure HelloMnemo. L’objectif est la continuité entre appareils sans traiter l’archive comme du texte clair dans le cloud.

Les détails évoluent avec les versions ; considérez cette page comme une vue d’ensemble et la documentation pour l’orientation opérationnelle.

### Ce que vous pouvez faire

- Préférez l’usage hors ligne si vous ne voulez pas de synchronisation cloud.
- Utilisez l’export quand vous avez besoin d’une copie portable (voir [Importer et exporter](docs/getting-started/import-export/)).
- Protégez l’appareil au niveau système (code, chiffrement du disque, effacement à distance).

### Signaler un problème

Si vous pensez avoir trouvé un problème de sécurité, écrivez à [info@hellomnemo.com](mailto:info@hellomnemo.com) avec assez de détails pour reproduire. Évitez de publier des exploits avant que nous puissions répondre.
