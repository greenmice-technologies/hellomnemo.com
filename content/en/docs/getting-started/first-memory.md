This guide describes a simple first session that validates the basics: **capture, browse, search**.

## Before you begin

- Install Mnemo from the official store for your platform.
- Decide whether you are starting **local-only** or signing in for sync (optional).

## Steps

1. **Create or open your workspace**  
   Use the app onboarding until you reach the main timeline or home surface.

2. **Create a new entry**  
   Add a short note you will recognize tomorrow (for example: “First Mnemo entry — setup day”).

3. **Add context**  
   Set a date if needed, attach a photo if you want, and save.

4. **Find it again**  
   Use search or browse by day to reopen the entry.

## Success criteria

You can reliably answer: “If I saved it today, can I find it again without guessing?”
