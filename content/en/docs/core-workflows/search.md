## Goal

Return to the right fragment **fast**, especially months after capture.

## Text search

Start broad, then narrow:

- use distinctive phrases you remember writing
- try names, places, and project keywords

## Time and place

Calendar and map surfaces help when you remember **when** or **where**, but not exact wording.

## When search fails

Usually one of these is true:

- the entry lives in an unexpected folder
- the keyword differs from what you wrote
- media was captured without much text context

Fix forward by adding one anchor sentence at capture time (“Context: …”).
