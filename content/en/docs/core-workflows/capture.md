## Goal

Make “save this moment” so easy that you actually do it—without sacrificing structure later.

## Recommended habits

- **Default to short** notes; expand only when you have energy.
- **Attach media early** (photo, audio) while the context is fresh.
- **Trust the timestamp**; fix timezones only when it materially changes meaning.

## Entry types and media

Mnemo is built to combine **text** with **photos, video, audio, and documents** in a single memory surface. If a capture type is unavailable in your build, update the app or check platform limitations.

## Reminders

Use reminders when memory is **time-sensitive** (“call back Tuesday”) vs purely archival (“trip journal”).
