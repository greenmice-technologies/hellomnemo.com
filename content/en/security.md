Security for Mnemo starts with a simple principle: **your memory is yours**. The product is designed so everyday use does not depend on sharing more data than necessary.

### Offline-first by default

Your primary dataset is stored **locally on device**. That reduces accidental exposure and keeps the app usable in low-connectivity environments.

### Optional cloud sync

If you enable account-backed features, Mnemo can synchronize an **encrypted dataset and encrypted media** with HelloMnemo infrastructure. The goal is continuity across devices without treating your archive as plaintext in the cloud.

Details evolve with releases; treat this page as a high-level overview and use the documentation for operational guidance.

### What you can do

- Prefer offline use if you do not want cloud sync.
- Use export paths when you need a portable backup (see [Import & export](docs/getting-started/import-export/)).
- Keep your device protected with OS-level security (passcode, disk encryption, remote wipe).

### Reporting

If you believe you have found a security issue, contact us at [info@hellomnemo.com](mailto:info@hellomnemo.com) with enough detail to reproduce the problem. Please avoid posting exploit details publicly until we have a chance to respond.
