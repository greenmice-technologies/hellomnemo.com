Para Mnemo el punto de partida es simple: **tu memoria es tuya**. El producto está diseñado para que el uso diario no dependa de compartir más datos de lo necesario.

### Offline-first por defecto

Tu conjunto de datos principal se almacena **localmente en el dispositivo**. Esto reduce la exposición accidental y mantiene la app usable con conectividad limitada.

### Sincronización opcional en la nube

Si habilitas funciones vinculadas a la cuenta, Mnemo puede sincronizar **conjunto de datos y medios cifrados** con la infraestructura HelloMnemo. El objetivo es continuidad entre dispositivos sin tratar el archivo como texto plano en la nube.

Los detalles evolucionan con las versiones; considera esta página una visión general y usa la documentación para orientación operativa.

### Qué puedes hacer

- Prefiere el uso sin nube si no quieres sincronización.
- Usa la exportación cuando necesites una copia portable (véase [Importar y exportar](docs/getting-started/import-export/)).
- Protege el dispositivo a nivel de sistema (código, cifrado de disco, borrado remoto).

### Informes

Si crees haber encontrado un problema de seguridad, escribe a [info@hellomnemo.com](mailto:info@hellomnemo.com) con suficiente detalle para reproducirlo. Evita publicar exploits antes de que podamos responder.
