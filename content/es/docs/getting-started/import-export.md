Mnemo admite flujos de **importación y exportación** para que tu memoria sea portable.

## Por qué importa

- **Copia de seguridad**: una copia independiente de un solo dispositivo.
- **Migración**: pasar a un teléfono o tablet nuevo con menos fricción.
- **Tranquilidad**: tu archivo no queda “atrapado” en una instalación.

## Orientación práctica

Las etiquetas de la interfaz cambian con el tiempo, pero la intención es estable:

1. Usa **exportar** para generar un paquete con el conjunto de datos y los medios referenciados.
2. Guarda el paquete donde tú controles (disco cifrado, nube personal, etc.).
3. Usa **importar** en una instalación nueva para restaurar o fusionar con cuidado con duplicados.

## Consejos de seguridad

- Trata las exportaciones como datos sensibles—**cifra el almacenamiento** y limita el uso compartido.
- Tras cambios importantes, crea una exportación nueva en lugar de asumir que una copia antigua sigue siendo válida.
