Usa estas páginas en orden la primera vez que abras Mnemo.

1. [Crear una cuenta (opcional)](create-account/) — solo para funciones en la nube.
2. [Tu primera memoria](first-memory/) — captura y recupera una primera entrada.
3. [Importar y exportar](import-export/) — mueve datos como archivo portable.

Cuando te sientas cómodo, continúa con [Flujos principales](../core-workflows/).
